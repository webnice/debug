Библиотека golang

Отладочный дампер переменных

## Описание

`debug` — это библиотека для вывода дампа произвольных переменных в
удобочитаемом виде. Структуры выводятся с именами полей, `map` — с ключами,
срезы и массивы — с индексами, каждая строка дампа нумеруется, вложенность
отражается отступами. Дамп сопровождается заголовком с датой, местом вызова,
именем пакета и функции.

Библиотека бережно обращается с любыми данными: циклические ссылки не
приводят к зависанию, пустые ссылочные поля скрываются, значения-ошибки и
значения с методом `String()` выводятся их строковым представлением.

### Особенности

- Вывод любого количества переменных любых типов: структуры, `map`, срезы,
массивы, указатели, каналы, функции, интерфейсы;
- Нумерация строк и иерархические отступы, отражающие вложенность;
- Ключи `map` сортируются — дамп воспроизводим между запусками;
- Защита от циклических ссылок: повторное вхождение объекта выводится как
ссылка `(obj @ N)` на строку первого вывода;
- Пустые ссылочные поля структур (`nil`) скрываются фильтром;
- Значения, реализующие `error`, выводятся текстом ошибки; значения с методом
`String()` — результатом этого метода;
- Четыре способа вывода: STDOUT, строка, `[]byte`, файл;
- Поиск забытых отладочных вызовов: `Nop()` по переменной окружения
`DEBUG_CALLS` выводит имя файла и строку каждого вызова;
- Дамп полного стека всех горутин по `DEBUG_TRACESTACK` или `SeeCallStack()`;
- Окончания строк CRLF/LF: в Windows по умолчанию CRLF, принудительный
переключатель — переменная окружения `DEBUG_CRLF`;
- Нулевые зависимости, покрытие тестами 100%.

## Переменные окружения

| Переменная       | Значение         | Эффект                                                                       |
| ---------------- | ---------------- | ---------------------------------------------------------------------------- |
| `DEBUG_CALLS`    | `true`, `1`, `yes`, `on` | Каждый вызов `Nop()` выводит имя файла и номер строки вызова         |
| `DEBUG_TRACESTACK` | `true`, `1`, `yes`, `on` | К дампу добавляется полный стек вызовов всех горутин               |
| `DEBUG_CRLF`     | `true` / `false` | Принудительно включить или выключить окончания строк CRLF. По умолчанию: CRLF в Windows, LF в остальных ОС |

Значения `false`, `0`, `no`, `off` отключают соответствующий режим. При
незаданной или нераспознанной переменной используется поведение по умолчанию.

## Примеры использования

### Быстрый дамп в STDOUT

```go
package main

import (
	"github.com/webnice/debug"
)

type Config struct {
	Host string
	Port int
	TLS  any // пустое ссылочное поле будет скрыто фильтром
}

func main() {
	cfg := Config{Host: "localhost", Port: 8080}
	debug.Dumper(cfg)
}
```

Вывод:

```text
[ 11.11.2026 10:00:00:0000000000 ] ------------------------------------------------------------
[                 debug.Dumper() ] /home/user/project/main.go:16 [main] [main()]
000000: main.Config {
000001: 	Host: "localhost"
000002: 	Port: 8080
000003: }
-----------------------------------------------------------------------------------------------
```

### Дамп в строку и в срез байт

```go
// Дамп в строку: удобно передать в лог или тест.
s := debug.DumperString(cfg)

// Дамп в []byte: удобно записать куда-либо самостоятельно.
b := debug.DumperByte(cfg)
```

### Дамп в файл

```go
// Сохраняет дамп в файл <имя программы>.txt в текущей директории,
// дописывая в конец существующего файла.
debug.DumperFile(cfg)
```

### Карты, сортировка ключей и защита от циклов

```go
m := map[string]any{"version": 2, "name": "debug"}
m["self"] = m // циклическая ссылка: не приводит к зависанию
debug.Dumper(m)
```

Вывод (ключи отсортированы, повторное вхождение — ссылкой):

```text
000000: map[string]interface {} (len = 3) {
000001: 	"name": "debug"
000002: 	"self": map[string]interface {} (obj @ 0)
000003: 	"version": 2
000004: }
```

### Поиск забытых отладочных вызовов

```go
// Nop() ничего не делает, но оставляет точку в коде, которую легко найти.
debug.Nop()
```

Запуск программы с `DEBUG_CALLS=1` выводит место каждого вызова:

```text
[                    debug.Nop() ] /home/user/project/main.go:22
```

### Дамп со стеком вызовов

```go
// Включает вывод полного стека всех горутин для последующих дампов.
// Аналогично запуску с DEBUG_TRACESTACK=true.
debug.SeeCallStack(true)

debug.Dumper(cfg) // дамп будет дополнен стеком вызовов
```
